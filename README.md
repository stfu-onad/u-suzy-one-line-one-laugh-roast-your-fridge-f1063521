# One Line, One Laugh: Roast Your Fridge

One line roasting the entrant's own fridge: it groans at every opening
like a judge, and the verdict inside is just as harsh.

## Run

```sh
python3 main.py
cat /output/entry.txt
```

`main.py` validates the line (single line, 1–199 characters, not blank)
and writes it plus a trailing newline to `/output/entry.txt`.
